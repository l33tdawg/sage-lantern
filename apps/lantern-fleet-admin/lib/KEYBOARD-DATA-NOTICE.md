# English keyboard vocabulary

`keyboard-words.en.json` is adapted from FrequencyWords by Hermit Dave and
contributors, using OpenSubtitles2018 frequencies.

Source: https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/en/en_50k.txt

Changes: retain ASCII alphabetic words of 1–32 characters with source frequency
at least 1,000; lowercase and deduplicate without changing source order; omit
frequency counts and serialize as JSON. Result: 17,306 entries. Punctuation is
not stripped; contractions containing apostrophes are excluded rather than
rewritten. The upstream data license is distinct from its MIT code license.

This is an English evaluation vocabulary, not a multilingual or next-word model.
Names, fragments and offensive terms may remain; filtering does not establish
vocabulary quality. Suggestions require explicit acceptance and do not silently
change input. No typing is transmitted to the source project or any cloud service.
