# Security Policy

SAGE Commons is pre-release. No version is yet eligible for a production security-support promise.

Do not publish a suspected vulnerability, secret, private memory, identity material or validator detail in a public issue. Until a dedicated private disclosure address and response team are approved, contact the repository owner privately and label the report `SAGE Commons security`. The Foundation MUST publish a durable security contact before the first external alpha.

Reports should include the affected component and version, prerequisites, reproducible impact, whether personal/private/public data can cross boundaries, and any known workaround. Do not access data or systems beyond those you own or are explicitly authorized to test.

The project will publish supported versions, acknowledgement targets, severity rules, coordinated-disclosure timelines and signed advisories before operating a public network.
