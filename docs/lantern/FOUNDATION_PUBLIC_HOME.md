# Foundation public home

User decision, 2026-09-06: the user has purchased `sage.ngo` and intends it
to be the public home for SAGE Lantern and the broader foundation initiative.

The site should explain the mission, how Lantern works, and how people can
get involved. Suggested content includes sponsorship, contributions, field
deployment updates, governance/transparency and technical documentation.

This records the intended domain and scope only. DNS, hosting, email,
publication, foundation incorporation and donation processing are not set up
or verified by this decision. No private Lantern service or ledger should be
exposed merely because the public website uses this domain.

Unit A completion and independent Unit B provisioning remain the current
engineering priority; a website launch is a separate deliverable.
